## Quick Reference

**What is this?** A persistent, intelligent memory layer for AI applications and agents — a Memory Intelligence Gateway.

**Current status?** Working .NET 10.0 LLM proxy with knowledge injection. Full memory intelligence pipeline is planned.

**How to run?** `cd DeveloperMemory.Api && dotnet run` (requires .NET 10.0 SDK).

**What's the vision?** See [PROJECT_VISION.md](PROJECT_VISION.md) for the full vision.

**What's implemented?** See [CURRENT_STATUS.md](CURRENT_STATUS.md) for an honest assessment.

**What's next?** See [ROADMAP.md](ROADMAP.md) for the development roadmap.

**Want to implement something?** See [AGENTS.md](AGENTS.md) for coding standards and [CLAUDE.md](CLAUDE.md) for the technical specification.
