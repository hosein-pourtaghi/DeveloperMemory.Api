# CONTRIBUTING.md## Project OverviewDeveloper Memory API is a .NET 10.0 Web API for knowledge management and AI assistant gateway.## How to Contribute1. **Fork the repository** and clone your fork locally.2. **Create a feature branch** for your changes.3. **Write descriptive commit messages** that clearly describe your changes.4. **Submit a pull request** for code review.5. **Ensure your code follows the coding standards** defined in AGENTS.md.6. **Add or update documentation** as needed, following the documentation guidelines.## Coding StandardsPlease follow the coding standards defined in AGENTS.md, including:- Naming conventions (PascalCase for classes/methods/properties, camelCase for variables/parameters)- File organization (Controllers in Controllers/, Services in Services/, etc.)- XML comments for public methods- Error handling with try-catch blocks and appropriate HTTP status codes- Logging errors using Serilog- Writing unit tests for service methods with coverage above 80%## Documentation Guidelines- Update relevant documentation files when adding features- Follow the existing documentation structure- Ensure all public APIs are documented with XML comments## Error Handling- Use try-catch blocks in controllers- Return appropriate HTTP status codes- Log errors using Serilog## Testing- Write unit tests for service methods- Test edge cases and error conditions- Maintain test coverage above 80%## Issue ReportingPlease report bugs and feature requests through GitHub issues, providing clear descriptions and steps to reproduce.
